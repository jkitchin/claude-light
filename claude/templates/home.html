Claude-Light

A real instrument you can run experiments on from anywhere.

Claude-Light is a remote-controlled instrument for learning statistics, regression, optimization and design of experiments. You set the brightness of a red, green and blue LED, and a spectral sensor measures the light at 8 visible wavelengths plus clear and near-infrared. There is one real instrument, shared by everyone, sitting in a lab at Carnegie Mellon University.

Use it from code

Pass R, G and B levels from 0 to 1 and get JSON back:

curl "https://claude-light.cheme.cmu.edu/api?R=0.12&G=0.45&B=1"

In Python, install the claude-light-python package, or use requests directly:

import requests
resp = requests.get('https://claude-light.cheme.cmu.edu/api',
                    params={'R': 0.12, 'G': 0.45, 'B': 1})
resp.json()['out']['515nm']

Each measurement takes about 0.7 s. If the instrument is busy you will get HTTP 503 (queue full) or 429 (you already have measurements waiting) with a Retry-After header; wait and try again. See the API docs for all the endpoints.

or npx skills add jkitchin/claude-light --skill claude-light. See the guide for more.

The instrument

It is small: a Raspberry Pi drives an RGB LED, an AS7341 spectral sensor reads the light, and a Pi camera can take a picture. Your request joins a queue, the LED is set, the sensor integrates the light, and the readings come back as JSON.

Because it is a real device, repeated measurements are not identical. That is the point: you analyze data from a lab instrument, not a simulation.
